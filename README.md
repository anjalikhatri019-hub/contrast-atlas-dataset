# CONTRAST ATLAS participant dataset v1.0.6

This public release contains only participant-safe data. It contains no organizer raw source archive, held-out reference image, private answer, or source-ID map. The upstream material is the [Smartphone Image Denoising Dataset](https://abdokamel.github.io/sidd/), published under MIT. The root [LICENSE](LICENSE) applies to this derived public release. Original attribution and transformation details are in [SOURCE_LICENSE_NOTICE.md](SOURCE_LICENSE_NOTICE.md).

Download `participant_dataset.zip` (603,706,722 bytes; SHA-256 `4daec101c18ffdddf8b7edf6cae2a2fb2b792e6c4f2759eef3ab088c9f5dfc5f`). The [member manifest](public_release_manifest.json) records the SHA-256 and byte length of each of its 2,602 members; `python verify_release.py participant_dataset.zip` checks the asset.

The ZIP includes 1,440 noisy tiles, 1,152 training reference tiles, measured training rewards, the evaluation tile index, and a nonconstant noisy-tile-only sample. Its images and CSV members are byte-identical to v1.0.5. Version v1.0.6 updates only the challenge title, problem description, rubric, and dataset-card scoring instructions. The frozen training and private `action` labels remain legacy additive-knapsack baselines. The current challenge scores a spatially coupled allocation on the same measured gains. See [DATASET_CARD.md](DATASET_CARD.md) for schemas and limitations.
