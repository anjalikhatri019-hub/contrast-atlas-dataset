# CONTRAST ATLAS participant dataset v1.0.5

This public release contains only participant-safe data. It contains no organizer raw source archive, held-out reference image, private answer, or source-ID map. The upstream material is the [Smartphone Image Denoising Dataset](https://abdokamel.github.io/sidd/), published under MIT. The root [LICENSE](LICENSE) applies to this derived public release. Original attribution and transformation details are in [SOURCE_LICENSE_NOTICE.md](SOURCE_LICENSE_NOTICE.md).

Download `participant_dataset.zip` (603,649,176 bytes; SHA-256 `2cc00d0d21c0c85cec4237f4c2b9e1c44fb3e4c81720ad2e5058d966eb0c12dd`). The [member manifest](public_release_manifest.json) records the SHA-256 and byte length of each of its 2,602 members; `python verify_release.py participant_dataset.zip` checks the asset.

The ZIP includes 1,440 noisy tiles, 1,152 training reference tiles, measured training rewards, the evaluation tile index, and a nonconstant, noisy-tile-only sample submission. The submission and private answer schema is `tile_id,gain_1,gain_2,gain_3,action`; `image_id` remains a public input grouping field in `test_tiles.csv` and is not an answer target. The identity-action gain is implicitly zero, so the training rewards CSV stores only gains 1–3. The challenge scores forecast accuracy, measured utility, and policy alignment. See [DATASET_CARD.md](DATASET_CARD.md) for the schemas and limitations.
